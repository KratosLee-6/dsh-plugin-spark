# Evidence review / 证据审阅

Review the supplied evidence and record uncertainties. Keep private material local.

## Steps / 步骤
- Check the source of each claim.
- List unanswered questions before proposing actions.

## Constraints / 约束
- Do not claim an unverified statement is a fact.

## Notes / 补充说明
Inputs and outputs are deliberately unspecified. Review and define them in Spark before importing.
